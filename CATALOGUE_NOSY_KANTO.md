# Règles de nommage

- Un produit possède un nom court.
- Le nom n'est jamais une description commerciale.
- La description contient les détails marketing.
- Le SKU est une référence interne.
- Le slug est réservé au site Internet.
- Une collection représente une famille de créations.

---

# Structure d'un produit

| Champ | Rôle |
|-------|------|
| name | Nom affiché |
| slug | Adresse du site |
| sku | Référence interne |
| category | Catégorie commerciale |
| collection | Collection |
| description | Description commerciale |
